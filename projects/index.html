TUIX Core

0.5

TUIX Core is a Python terminal UI engine built on a compiled C + Cython core. Version 0.5 focuses on stability and composition: safer buffer ownership, lower render-path lock contention, nested row/column/split/grid layouts, viewport-aware widgets, modal dialogs, richer snapshots, scene transactions, and mouse capture APIs.
