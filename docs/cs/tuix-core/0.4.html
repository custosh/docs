TUIX v0.4Beta

Naposledy aktualizováno: 2026-05-20

Přehled TUIX Core v0.4

TUIX Core je modulární terminálový UI engine pro Python. Kombinuje kompilované renderovací jádro v C s mostem v Cythonu a Python API, aby poskytl vysoce výkonná interaktivní terminálová rozhraní — interaktivní menu, ukazatele průběhu, textové vstupy a volně kreslená plátna.

Verze 0.4 rozšiřuje architekturu C + Cython o větší sadu builderů, generování hitmapy kompozitoru pro každý snímek, výběr kliknutí myší přes hitmapu, nekomzumující API input.peek_snapshot() a zpřísnění concurrency napříč cestami registry, scén, subcyklů a objektů.

Architektura

TUIX používá třívrstvý návrh: dole kompilovaný engine v C, uprostřed Cython wrapper a nahoře Python API. Veškeré renderování, kompozice a snímání vstupu běží v C. Pythonová vrstva poskytuje životní cyklus scén, konfiguraci widgetů a hlavní smyčku.

Rozvržení založené na scénách

Widgety žijí uvnitř scén. Každá scéna obsahuje seřazený seznam bufferů, které se v pořadí painter's order skládají do finálního framebufferu. Geometrie je proporcionální — velikosti a okraje widgetů jsou vyjádřeny jako zlomky 0.0–1.0 aktuálních rozměrů terminálu a přepočítávají se v každém snímku.

Multiplatformní vstup

Vstup běží ve vyhrazeném vlákně. Na Windows používá ReadConsoleInputW pro nativní události klávesnice a myši. Na POSIX systémech používá raw mode a parsování myši ve formátu SGR. Události se ukládají do bezlockových kruhových bufferů (128 událostí na frontu) a každý snímek se čtou jako snapshoty.

Proporcionální layout engine

Všechny rozměry a pozice widgetů jsou vyjádřeny jako desetinné modifikátory (0.0–1.0) relativně k velikosti terminálu. Resolver geometrie tyto modifikátory v každém snímku násobí aktuální šířkou a výškou terminálu, takže se widgety automaticky přizpůsobí při změně velikosti terminálu.

Podporované platformy

TUIX Core podporuje Windows (x86, AMD64), Linux (x86_64, i686, aarch64) a macOS (x86_64, arm64). Předpřipravená wheel balení jsou dostupná pro Python 3.10+. Terminál musí podporovat ANSI escape sekvence. Pokud je k dispozici truecolor (24bit RGB), použije se automaticky, jinak systém spadne zpět na ANSI256 a ANSI16 palety.

Co je nového

  • Nový systém zpracování vstupu pro buildery (vstup je nyní nativní a automatický)
  • Naslouchání vstupu je ve standardním běhu stále explicitní (spuštění přes input.listen(), ukončení přes input.stop())
  • Přidána hierarchie bufferů s parent_uid, včetně ochrany proti self-parent a cyklům
  • Přidáno bezpečné pře-rodičovství potomků při smazání rodičovského bufferu
  • Resolver geometrie nyní podporuje parent-relative layout
  • Kompozitor nyní používá traversal-chain vrstvení pro parent/child stromy
  • Přidáno řazení root bufferů podle z-index a veřejné API pro get/set z-index
  • Přidány lock-safe snapshoty bufferů a lock-safe snapshoty objektů podle UID
  • Z veřejného API odstraněny raw buffer pointer gettery (cleanup v0.x)
  • Canvas a ukázkové aplikace byly refaktorovány na snapshot API
  • Main loop zmenšil rozsah locku okolo builder callbacků v cestě generování bufferů
  • Soubory subcycles manageru byly odstraněny z veřejného povrchu dokumentace; subcykly jsou interní řídicí objekty
  • Přidána instrumentace aktivity scén: frame counter, last_active_frame, last_compacted_frame
  • Přidána API pro statistiky a kompaktaci scén: get_scene_stats(), compact_scene_pixels(), compact_cold_scenes()
  • Strategie cache je nyní data-first: měření a kompaktace studených scén místo eager globální cache

Známá omezení (v0.4)

  • Chybí vestavěný systém témat/stylů nad rámec stylování jednotlivých widgetů.
  • Hlavní smyčka je synchronní; async-friendly integrace smyčky není vestavěná.
