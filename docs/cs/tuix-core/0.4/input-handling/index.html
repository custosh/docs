TUIX v0.4Beta

Naposledy aktualizováno: 2026-05-20

Zpracování vstupu

TUIX zachytává vstup z klávesnice a myši ve vyhrazeném vlákně na pozadí a předává události widgetům pomocí snímků. Ve v0.4 je zpracování vstupu ve výchozí builder pipeline automatické a peek_snapshot() poskytuje nekomzumující čtení aktuálního stavu.

Architektura

Vstupní systém běží jako vlákno na pozadí spuštěné pomocí input.listen(). Čte surové události platformy a ukládá je do dvou kruhových bufferů: jeden pro klávesnici a jeden pro myš. Každý buffer pojme až 128 událostí. Ve standardním použití v0.4 snapshoty automaticky spotřebovává frame loop a builder callbacky, zatímco peek_snapshot() umožňuje kontrolu aktuálního stavu bez jeho posunu.

Snímky vstupu

Snímek je okamžitý záznam stavu vstupu. Obsahuje aktuální rozměry terminálu a ukazatele na data událostí klávesnice a myši.

# Automatic path (v0.4 default)
while running:
    engine.main_loop()

# Non-consuming inspection
snapshot = input.peek_snapshot()

Snapshoty jsou stále mostem mezi vstupním vláknem a logikou widgetů. V případě potřeby můžete input.get_snapshot() volat ručně, když chcete spotřebovat další snapshot, ale výchozí builder flow ve v0.4 to dělá za vás.

Události klávesnice obsahují kód klávesy, scancode, modifikační příznaky, stav stisku/opakování, časové razítko a až 8 bajtů UTF-8 textu.

Implementace na platformách

Na Windows používá vstupní vlákno ReadConsoleInputW pro příjem nativních struktur KEY_EVENT_RECORD a MOUSE_EVENT_RECORD. Stavový automat tlačítek sleduje hrany stisku/uvolnění pro přesnou detekci kliknutí. ENABLE_VIRTUAL_TERMINAL_INPUT se záměrně nepoužívá kvůli chybě Windows, kdy jsou SGR kódované události myši mylně vyhodnoceny jako klávesnicový vstup.

Na POSIX systémech (Linux, macOS) se terminál přepne do raw režimu a jedno vlákno pthread čte ze stdin. Události myši se parsují ze SGR escape sekvencí. Režim terminálu se obnoví po zavolání input.stop().

Vzor použití

from tuix.core import engine, input

input.listen()
while running:
    engine.main_loop()
input.stop()
Ruční kompatibilní cestaPokud potřebujete explicitní kontrolu, ruční API pro feed snapshotu stále existují (objects.tuix_choice_feed_input, objects.tuix_input_feed_input a další builder-specific feed cesty), ale pro běžné aplikace v0.4 už nejsou nutné.
Směrování fokusu (v0.4)Použijte scenes.set_focus(scene_name, uid) pro výběr interaktivního widgetu, který má dostávat fokus klávesnice, a scenes.set_previous_focus(scene_name) pro návrat na předchozí cíl.
