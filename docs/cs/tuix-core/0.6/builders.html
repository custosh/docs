API builderů

Balíček content_builder poskytuje názvy používané objects.create_object(), kanonické konstanty builderů, layout konstanty, registraci standardních builderů, namespaced odregistrování a helpery jednotlivých widgetů.

Metody

MetodaJak ji použítProč existuje
content_builder.tuix_builder_register_standard() -> intZavolejte jednou po core.init() a před tvorbou objektů.Zaregistruje každý vestavěný nativní builder pod namespace 'tuix' do aktuální registry jádra. Vrací TUIX_RC_OK (0).
content_builder.tuix_builder_unregister(namespace: bytes, name: bytes) -> intVolejte pro odregistrování vlastního nebo dynamicky načteného builderu podle namespace a jména.Bezpečně odstraní deskriptory builderu při uvolňování rozšíření bez narušení živých instancí.

Použití

core.init()
content_builder.register_standard()
scene.init_scene(b'Main')
scene.select_scene(b'Main')

uid = objects.create_object(content_builder.GRID, b'Main', 0.9, 0.6, 0.1, 0.05)
grid = objects.get_object_by_uid(uid)
objects.tuix_grid_set_columns(grid, [(content_builder.GRID_TRACK_WEIGHT, 1)])
