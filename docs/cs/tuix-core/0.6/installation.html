TUIX v0.6Beta

Naposledy aktualizováno: 2026-08-14

Instalace

TUIX Core je publikován jako Python balíček tuix-core. Předpřipravená wheel balení jsou očekávána pro Windows, Linux a macOS na běžných x86 a ARM architekturách.

Požadavky

  • Python >= 3.10.
  • Terminál s podporou ANSI; truecolor se použije, pokud je dostupný, jinak renderer použije fallback palety.
  • Pro build ze zdroje: Cython >= 0.29, setuptools, wheel a C kompilátor pro danou platformu.

pip

python -m pip install tuix-core

Build ze zdroje

git clone https://github.com/custosh/tuix-core.git
cd tuix-core
python -m pip install -U pip setuptools wheel Cython
python -m pip install -e .

Ověření instalace

from tuix.core import core, content_builder

core.init()
content_builder.register_standard()
print('TUIX Core v0.6 loaded successfully')
core.shutdown()

Časté problémy

  • Pokud po buildu ze zdroje selže import, ověřte, že kompilované rozšíření bylo sestaveno pro stejný Python interpreter, který spouštíte.
  • Pokud render vypadá špatně, vyzkoušejte terminál s podporou ANSI escape sekvencí a dostatečnou šířkou/výškou pro příklad.
  • Interaktivní widgety potřebují input.listen() před smyčkou a input.stop() při úklidu.
