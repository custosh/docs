TUIX Core Overview

TuixEngine is a console-based UI engine for Python for building interactive terminal interfaces with components, styling, and input handling.

Purpose

Quickly create interactive menus, progress bars, and text inputs in the terminal. TUIX Core provides customizable styles, layout control, and input handling out of the box.

Currently fully supports single choice components; multi-modal layouts and additional component types are planned for the future.

Key Features

Text and Background Styling

Full RGB colors via ANSI 24-bit escape codes, optional shadows computed with blend_shadow(), and text formatting options: bold, italic, underline, dim. Styles use a cascading configuration — presets provide base values, custom overrides take precedence.

Components

Three component types are supported: choice (multi-row selection menus with keyboard navigation), progress_bar (visual progress indicator), and text_input (single-line text entry). Each component has a unique ID, configurable properties, and layout parameters.

FuturePlanned components include sliders, checkboxes, and additional interactive elements.

Layout Engine

Positions are calculated as proportional modifiers (0.0–1.0) of the terminal size, recomputed on every render via shutil.get_terminal_size(). Components can use custom margins or be automatically centered.

FuturePlanned: multi-object layout with collision detection.

Render Engine

Draws components to the terminal using Unicode box-drawing characters (┏, ┓, ┗, ┛, ━, ┃) and ANSI color codes. Currently only the choice component type is fully implemented for rendering.

FuturePlanned: full multi-component rendering for all component types.

Input Handling

Cross-platform keyboard input: Windows (msvcrt) and Unix-like (termios, tty, select). Arrow keys for navigation and Enter for confirmation.

FuturePlanned: additional key bindings and multi-component focus management.

Platform Support

TUIX Core works on Windows, macOS, and Linux. On Windows, it enables virtual terminal processing via kernel32.SetConsoleMode at import time. On Unix systems, it uses termios and tty for raw keyboard input. The framework requires a terminal that supports ANSI escape sequences and 24-bit (truecolor) RGB output.
